# Reference style analysis

No copyrighted question text is stored here. External books were used only as aggregate design evidence. Microsoft Learn / current official documentation remain the sole factual authority.

## Reference A — current Microsoft authority

Facts, terminology, exam scope, and the 58-leaf map stay on the 2026-07-28 study-guide freeze. Stale book terms such as Azure AD, Azure Sentinel, Microsoft 365 Defender, Azure Purview, Compliance Center, and Azure Blueprints were not imported.

## Reference B — Microsoft Practice Assessment (style floor)

Observed as the official wording/style floor, not as a content source:

- short stems
- direct definition and capability recognition
- one-step scenarios
- modest reading load
- weaker than a typical live Fundamentals exam

The calibrated bank is intentionally above this floor.

## Reference C — independent SC-900 question book

Aggregate signals only:

- mostly direct concept recognition and service/capability matching
- short scenarios and straightforward terminology items
- some true/false
- some easy distractors and undesirable all/none-of-the-above patterns
- older terminology in places

Those factual claims were not treated as authority.

## Reference D — 2022 Packt mock exam

Printed pages 348–360 (PDF pages 371–383 in the local file) contain a 65-item mock exam. Aggregate extraction found:

| Characteristic | Observation |
| --- | --- |
| Typical item length | median about 32 words; p90 about 55 |
| True/false | common (about 16 flags in the mock-exam pages) |
| NOT/EXCEPT | present in moderation (about 11 flags) |
| Which-service / what-is | present but not dominant |
| Multi-select | rare |
| Company-name scenarios | uncommon |
| Stale terminology | frequent Azure AD hits; some Compliance Center / Blueprints |

The book is copyrighted and from 2022. No question text, answers, or explanations were copied. Stale product names were treated as style evidence only.

## Design conclusion

| Dimension | Practice Assessment | Independent books | Pre-calibration bank | Calibrated target |
| --- | --- | --- | --- | --- |
| Reading load | low | low/moderate | already low (median 20 words) | keep short |
| Cognitive steps | 0–1 | 0–1, some 2 | too many 2-step / claim-diagnosis items | 0–1 for normal testing |
| Distractors | mixed, some weak | often easy | too many cross-product jokes | neighboring concepts |
| Stretch share | near zero | small | too high in practice | 5–10% |

Final mix chosen from this evidence: about 66% Core, 29% Applied, 5% Stretch — above Microsoft Practice, below the previous adversarial average, and consistent with the book samples.
